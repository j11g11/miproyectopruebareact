# Paradise Nursery

**Paradise Nursery** is a React + Redux Toolkit e-commerce application for purchasing indoor plants.

## Project name
Paradise Nursery

## Main features
- Landing page for Paradise Nursery
- About Us information
- Product list grouped into three categories
- 18 unique indoor plants with thumbnails, names and prices
- Add to Cart functionality with disabled buttons after selection
- Dynamic cart item counter
- Shopping cart with quantity controls and delete actions
- Total per product and total cart cost
- Continue Shopping navigation
- Checkout button with a "Coming Soon" message
- Redux Toolkit used for cart state management

## Technologies
- React
- Redux Toolkit
- React Redux
- React Router
- Vite

## Run locally

```bash
npm install
npm run dev
```
